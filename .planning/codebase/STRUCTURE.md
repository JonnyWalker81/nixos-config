## Directory Purposes

**`lib/`:**
- Purpose: System builder helper functions
- Contains: Single file `mksystem.nix` - the unified system configuration factory
- Key files: `lib/mksystem.nix`

**`machines/`:**
- Purpose: Per-machine system-level NixOS/Darwin configurations
- Contains: One `.nix` file per machine configuration, plus `vm-shared.nix` for shared Linux VM settings
- Key files:
  - `machines/vm-aarch64-prl.nix`: Primary active config (ARM64 Parallels VM, time sync, clock skew detection)
  - `machines/vm-aarch64.nix`: ARM64 VMware VM (old kernel 6.1)
  - `machines/vm-intel.nix`: x86_64 VMware VM
  - `machines/vm-shared.nix`: Shared Linux VM config (WM toggles, boot, fonts, system packages, services)
  - `machines/vm-darwin.nix`: macOS Darwin (empty - config lives in user darwin.nix)
  - `machines/macbook-cipher.nix`: macOS for cipher (empty)
  - `machines/macbook-phantom.nix`: macOS for phantom (empty)

**`hardware/`:**
- Purpose: Hardware-specific NixOS configs (generated by `nixos-generate-config`)
- Contains: Kernel modules, filesystem definitions, swap config, CPU microcode
- Key files: `hardware/vm-aarch64-prl.nix`, `hardware/vm-aarch64.nix`, `hardware/vm-intel.nix`
- Note: Only Linux machines have hardware configs; Darwin machines don't need them

**`modules/`:**
- Purpose: Reusable NixOS modules using the options/config pattern
- Contains: Window manager toggles, VM guest integration, display management
- Key files:
  - `modules/desktop/default.nix`: Barrel import for all WM modules
  - `modules/desktop/dwm.nix`: DWM toggle (`desktop.dwm.enable`)
  - `modules/desktop/xmonad.nix`: XMonad toggle (`desktop.xmonad.enable`)
  - `modules/desktop/awesome.nix`: AwesomeWM toggle (`desktop.awesome.enable`)
  - `modules/desktop/hyprland.nix`: Hyprland toggle (`desktop.hyprland.enable`)
  - `modules/parallels-guest.nix`: Full Parallels Tools integration (replaces upstream module)
  - `modules/parallels-clipboard-x11-bridge.nix`: Clipboard sync between VM and macOS host
  - `modules/parallels-display.nix`: Display optimizations for Parallels VMs
  - `modules/display-x11.nix`: X11 display profile management with DPI/scaling options
  - `modules/display-profiles.nix`: Aggregator for display-x11 and parallels-display
  - `modules/vmware-guest.nix`: Custom VMware guest module (replaces upstream for aarch64)

**`overlays/`:**
- Purpose: Nixpkgs package overrides and custom package injection
- Contains: Overlay files in three categories
- Key files:
  - `overlays/default.nix`: Core overlays (terraform, parallels-tools kernel extensions)
  - `overlays/unstable-packages.nix`: Packages pulled from nixpkgs-unstable (kitty, xmobar, awscli2, ghostty)
  - `overlays/dwm.nix`: Custom DWM build from GitHub repo (pinned commit)
  - `overlays/picom.nix`: Picom compositor from upstream GitHub (pinned commit)
  - `overlays/nixvim.nix`: Nixvim from flake input
  - `overlays/fonts.nix`: DankMono font derivation from flake input
  - `overlays/tree-sitter.nix`: Tree-sitter grammar ABI 13 fixes (tsx, go)
  - `overlays/vim-plugins.nix`: Vim plugin build fixes (CopilotChat, neotest, nvim-nio, fzf-lua)
  - `overlays/firefox-hidpi.nix`: Firefox HiDPI wrapper script

**`pkgs/`:**
- Purpose: Custom package derivations for software not in nixpkgs or needing customization
- Contains: Terraform binary builder, Parallels Tools kernel module
- Key files:
  - `pkgs/terraform-bin.nix`: Terraform binary package (calls generic HashiCorp builder)
  - `pkgs/hashicorp/generic.nix`: Generic HashiCorp binary package builder
  - `pkgs/parallels-tools/default.nix`: Parallels Tools kernel module derivation
  - `pkgs/parallels-tools/prlfsmountd-nixos.patch`: Patch for NixOS compatibility
  - `pkgs/opencode-fhs.nix`: OpenCode FHS wrapper

**`users/`:**
- Purpose: All user-specific configuration including home-manager, dotfiles, and application configs
- Contains: Per-user directories with `nixos.nix`/`darwin.nix`/`home-manager.nix`, shared `common/` modules, and application config directories
- Key patterns:
  - Per-user dirs: `users/<username>/` with `nixos.nix`, `darwin.nix`, `home-manager.nix`
  - Shared modules: `users/common/` with concern-based splits
  - Dotfile dirs: `users/<app>/` containing raw config files symlinked via home-manager

**`scripts/`:**
- Purpose: System-level shell scripts for display, Hyprland, Parallels, SSH management
- Contains: Executable shell scripts referenced from Nix configs and shell aliases
- Key files:
  - `scripts/display-profiles/display-switcher.sh`: Main display profile switching script
  - `scripts/display-profiles/profile-*.sh`: Individual profile scripts (hidpi, retina, standard, present, ultrawide)
  - `scripts/setup-wallpaper.sh`: Desktop wallpaper setup
  - `scripts/ssh-key-manager.sh`: SSH key management
  - `scripts/hyprland-make-master.sh`: Hyprland window management helper
  - `scripts/hyprland-cycle-layout.sh`: Hyprland layout cycling
  - `scripts/cleanup-ssh-agents.sh`: SSH agent cleanup
  - `scripts/parallels-focus-fix.sh`: Parallels focus issues workaround
  - `scripts/screenshot.sh`: Screenshot utility

**`docs/`:**
- Purpose: Documentation for specific solutions and setups
- Contains: Markdown files documenting clipboard solutions, Gmail setup, SSH fixes
- Key files: `docs/CLIPBOARD-SOLUTION.md`, `docs/gmail-gcal-setup.md`, `docs/ssh-password-fix-summary.md`

## Key File Locations

**Entry Points:**
- `flake.nix`: Main flake entry point (all system configurations defined here)
- `Makefile`: Convenience build/deploy commands
- `lib/mksystem.nix`: System builder function (resolves machine + user configs)

**Configuration:**
- `flake.lock`: Pinned flake input versions
- `machines/vm-shared.nix`: Shared Linux VM system config (WM toggles, boot, fonts, services)

## Naming Conventions

**Files:**
- Machine configs: `<machine-name>.nix` in `machines/` (e.g., `vm-aarch64-prl.nix`)
- Hardware configs: `<machine-name>.nix` in `hardware/` (mirrors machine name)
- User OS configs: `nixos.nix` (Linux) or `darwin.nix` (macOS) in `users/<username>/`
- User home-manager: `home-manager.nix` in `users/<username>/`
- Common modules: `<concern>.nix` in `users/common/` (e.g., `packages.nix`, `shell.nix`, `git.nix`)
- Desktop modules: `<wm-name>.nix` in `modules/desktop/` (e.g., `dwm.nix`, `hyprland.nix`)
- Overlays: `<package-or-concern>.nix` in `overlays/` (e.g., `dwm.nix`, `unstable-packages.nix`)
- Custom packages: `<package-name>.nix` or `default.nix` in `pkgs/`
- Shell scripts: `kebab-case.sh` in `scripts/`

**Directories:**
- User directories: lowercase username (`cipher`, `jrothberg`, `phantom`)
- App config directories: lowercase app name under `users/` (`doom.d`, `ghostty`, `kitty`, `nvim`)
- Machine names: `<type>-<arch>[-<variant>]` pattern (e.g., `vm-aarch64-prl`, `macbook-cipher`)

**Nix Options:**
- Desktop toggles: `desktop.<wm>.enable` (e.g., `desktop.dwm.enable`)
- Parallels options: `hardware.parallels.*` (e.g., `hardware.parallels.enable`, `hardware.parallels.display.optimizations`)
- Display profiles: `services.xserver.displayProfiles.*`

## Where to Add New Code

**New Machine Configuration:**
1. Create `machines/<machine-name>.nix` with machine-specific config
2. Create `hardware/<machine-name>.nix` if it's a Linux machine with specific hardware
3. Add to `flake.nix` outputs using `mkSystem "<machine-name>" { system = "..."; user = "..."; }`
4. For Linux VMs: import `./vm-shared.nix` and relevant hardware/module files
5. For Darwin: set `darwin = true` and add `extraModules = [ inputs.nix-homebrew.darwinModules.nix-homebrew ]`

**New User:**
1. Create `users/<username>/` directory
2. Add `users/<username>/nixos.nix` (Linux system-level user definition)
3. Add `users/<username>/darwin.nix` (macOS system-level user definition) if needed
4. Add `users/<username>/home-manager.nix` - import `users/common/` and add user-specific config
5. Reference from `flake.nix` via `mkSystem "<machine>" { user = "<username>"; }`

**New Package Override (Overlay):**
- If it needs flake inputs: Create `overlays/<name>.nix` as `{ inputs }: final: prev: { ... }`, then import explicitly in `flake.nix` overlays list with `(import ./overlays/<name>.nix { inherit inputs; })`
- If self-contained: Create `overlays/<name>.nix` as `final: prev: { ... }`, then add `(import ./overlays/<name>.nix)` to `flake.nix` overlays list

**New Custom Package:**
- Create `pkgs/<package-name>.nix` or `pkgs/<package-name>/default.nix`
- Reference from an overlay in `overlays/` (typically `overlays/default.nix`) or directly from `users/common/packages.nix`

**New NixOS Module:**
- Create `modules/<module-name>.nix` with `options` and `config` sections
- Import from relevant machine config(s) in `machines/`
- For window manager: Create `modules/desktop/<wm>.nix` with `desktop.<wm>.enable` option, add to `modules/desktop/default.nix` imports

**New Shared User Package:**
- Add to `users/common/packages.nix` in the `home.packages` list
- Use `lib.optionals (!pkgs.stdenv.isDarwin) [ ... ]` for Linux-only packages
- Packages available to all users via common module import

**New Dotfile Configuration:**
- Create `users/<app>/` directory with raw config files
- Symlink via `home.file` in `users/common/dotfiles.nix` (shared) or `users/<username>/home-manager.nix` (user-specific)
- Pattern: `home.file."<target-path>" = { source = ../<app>/<file>; };`

**New Shell Script:**
- System-level: Add to `scripts/` directory
- User-level: Add to `users/scripts/` directory
- Reference from Nix config via absolute path or `pkgs.writeShellScriptBin`
- Add shell aliases in `users/common/shell.nix` if needed

**New Shell Alias:**
- Shared across users: Add to `users/common/shell.nix` in `programs.zsh.shellAliases` or `home.shellAliases`
- User-specific: Add to `users/<username>/home-manager.nix` in `home.shellAliases`

**New Common User Module:**
- Create `users/common/<concern>.nix` as a standard home-manager module
- Add import to `users/common/default.nix` imports list

## Special Directories

**`result/`:**
- Purpose: Nix build output symlink (created by `nix build`)
- Generated: Yes
- Committed: No (in `.gitignore`)

**`.planning/`:**
- Purpose: GSD planning and codebase analysis documents
- Generated: By AI tooling
- Committed: Yes

**`users/nvim-bak/`, `users/nvim-orig/`:**
- Purpose: Backup/original Neovim configurations (inactive, kept for reference)
- Generated: No
- Committed: Yes

**`users/nvim-kickstart/`:**
- Purpose: Kickstart.nvim configuration (has its own `.git` directory - submodule or copied repo)
- Generated: No
- Committed: Yes

**`users/doom.d/`:**
- Purpose: Doom Emacs configuration with custom modules
- Contains: `init.el`, `config.el`, `packages.el`, custom modules in `modules/`
- Committed: Yes
- Note: Symlinked to `~/.doom.d` via `users/common/dotfiles.nix`
